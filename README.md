### 🧠 技术方向

- **AI 应用工程化** — RAG 检索增强、Agent 编排、Workflow 引擎、Prompt 工程、LoRA 微调评估
- **后端与全栈** — Java / Python / TypeScript；Spring / FastAPI / Vue / React
- **基础设施与交付** — Docker / Kubernetes / Linux；Redis / MySQL / PostgreSQL；灰度发布、回滚、可观测性
- **AI Native 开发** — 基于 AI 与 Vibe Coding 做快速原型，从想法到可运行的东西

---

### 🧭 工程观

- **可审计 > 聪明** — 流程能追溯、责任能落地的方案，才敢进生产
- **可回滚 > 先进** — 能退回去的方案才敢上；不能停的系统就拆成可验证的小步走
- **从 demo 到上线的距离就是工程本身** — 权限体系、异常处理、日志告警，一样都省不掉
- **选型看场景，不看点名率** — 该 Workflow 就 Workflow，该 RAG 就 RAG；微调贵、知识变得快时，检索比训练诚实
