### 🧭 技术选型与判断

> 选型不看哪个先进，看哪个场景成立。三个真实案例：

| 场景 | 选择 | 不选 | 理由 |
|---|---|---|---|
| 金融智能客服（邮储，已全量上线） | **Workflow 编排 + RAG** | 纯 Agent | 流程可审计、责任可追溯 |
| SRE 运维知识问答（华为） | **主链路 RAG** | SFT 微调 | 知识更新快，微调成本高；仅固定格式输出用 LoRA 做评估 |
| 核心系统不停机迁移（国寿） | **分批次 + 灰度窗口 + 回退点** | 一次性切换 | 把「业务不能停」拆成可验证的小步骤 |

### 🔁 工程方法论

```
现场诊断 → 方案翻译 → 快速原型 → 工程落地 → 沉淀复用
```

**做什么**：把「客户没说出口的痛点」翻译成技术方案，再用 AI + Vibe Coding 快速做成能上线的东西。
**怎么做**：权限体系、异常处理、灰度回滚、日志告警——从 demo 到上线的差距，就是工程本身。
